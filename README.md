## Where to enter a Marriott promo code

The code box is hidden behind a rate selector, which is why so many people miss it. On marriott.com:

1. Run a normal search for your destination and dates.
2. On the results page, find the **"Special Rates"** dropdown.
3. Select **"Corporate/Promo/SET#"** and enter **QRI** in the code box.
4. Search again. Participating properties will show the discounted rate alongside standard pricing.

If no discounted rate appears, the hotel or your dates aren't covered — the search silently falls back to standard rates. No error message, no warning. Compare the two prices before assuming the code did nothing.

## Stacking the promo code with cash back

Here's what most coupon articles get wrong: they treat promo codes and cash back as either/or. They're not — with one caveat about the math.

Cash back portals calculate the rebate on the **post-discount, pre-tax subtotal**. A working promo code doesn't kill your cash back eligibility; it shrinks the base the percentage applies to. On that $2,000 stay, if QRI takes 20% off first, 6% applies to roughly $1,600 — about $96 back instead of $120. You still come out ahead of using either discount alone: $1,600 minus $96 beats $2,000 minus $120.

The genuine conflicts are the exclusions above.
